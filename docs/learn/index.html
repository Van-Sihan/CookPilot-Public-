코드에 대해 궁금한 것이 생기면 Claude 에게 물어보세요. 터미널에 답하는 대신 이 폴더에 문서 한 장이 새로 생깁니다. 이 페이지를 북마크해 두면 지금까지 배운 것을 한눈에 볼 수 있습니다.

목차

  • 01export, const, type — 파일 하나가 밖으로 무엇을 내놓는가

    파일끼리 값을 주고받는 방법, 값이 아니라 “모양”을 정하는 타입, 그리고 화면을 그리는 map·=>·백틱까지. site-content.ts 와 hero.tsx 를 예로 읽습니다.

  • 02데이터는 어디로 흐르는가 — API 키가 지나가는 길

    키를 넣으면 값이 어느 파일을 차례로 거쳐 저장되는지, 그리고 import 방향과 데이터 방향이 왜 반대인지. lib/domain · lib/usecase · lib/adapter 를 따라갑니다.

  • 03입력을 받아 처리하기까지 — 키보드에서 저장까지

    사용자가 친 글자가 어떻게 코드 안으로 들어오는지. useState · onChange · onSubmit · preventDefault 를 실험 4개와 함께 봅니다.

  • 04프로젝트 전체 코드 읽기 — 어느 파일부터 어떤 순서로

    저장소의 파일 스무 개를 이해하기 쉬운 순서로 하나씩 따라 읽습니다. layout → page → 부품 → site-content → globals.css → lib/ 순서로, 각 줄이 왜 있는지와 값이 어디로 흐르는지를 봅니다. 문서 안에 목차가 있어 필요한 자리로 바로 뛸 수 있습니다.

이 폴더의 규칙

  • 문서는 HTML 로 만듭니다. PDF 는 바이너리라 git 이 바뀐 곳을 비교하지 못하고, 고칠 때마다 파일이 통째로 쌓입니다.
  • 인쇄가 필요하면 브라우저에서 Ctrl+P → “PDF 로 저장” 을 쓰세요. 인쇄용 스타일을 넣어 두어 그대로 깔끔하게 나옵니다.
  • 보기를 바꾸고 싶으면 _assets/learn.css 한 파일만 고치면 문서 전부가 같이 바뀝니다.
  • 외부 자원(CDN 글꼴·이미지)을 쓰지 않습니다. 인터넷이 없거나 다른 컴퓨터에서 열어도 모양이 같아야 하기 때문입니다.
  • 파일 이름은 NN-슬러그.html. 번호는 만든 순서입니다.
