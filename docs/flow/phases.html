지도 B — 기능 · 데이터 구조 (FN01 – FN13 / D1 – D4)

저장 위치별로 접근 기능을 정리했다. Browser Storage 는 서버로 전송되지 않으며, External API 중 D4-1 · D4-2 · D4-5 는 브라우저가 서버를 거치지 않고 직접 호출한다.

COOKPILOT 서비스 흐름도 · 지도 C (1/2)

지도 C-1 · C-2 — 독립 기능과 로그인 경계

C-1 은 주요 요리 흐름과 독립적으로 사용 가능한 기능, C-2 는 저장 위치가 브라우저에서 Supabase 로 바뀌는 경계다.

COOKPILOT 서비스 흐름도 · 지도 C (2/2)

지도 C-3 — 오류 및 예외 처리 경로

검사 조건과 처리 결과만 표시한다. 검사 위치는 구현 근거를 참조한다. 처리 결과는 라우트 이동 4종과 현재 화면 처리 1종이다.
